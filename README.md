# ZyberGuard

ZyberGuard is a cybersecurity-focused application designed to help users
identify and understand common security risks.

## Features

- Security monitoring
- IP information lookup
- Port scanning
- File integrity checking
- SHA-256 hashing
- User-friendly interface

## Tech Stack

- Python
- PyQt5
- SHA-256
- REST API

## How to Run

1. Clone the repository
2. Install required dependencies
3. Run the main Python file

## Purpose

ZyberGuard was developed as a cybersecurity project for the hackathon.
